# Milestones

Create accepted milestones as zero-padded `mNNN.md` files. Companion files may
use `-notes.md`, `-handover.md`, and `-review.md` suffixes.

A milestone should be executable and bounded; future thoughts belong in
[`docs/planning/topics/`](../topics/README.md) until accepted.

Primary milestone documents are linked from the canonical
[roadmap](../roadmap.md). When adding a milestone to the roadmap, use a normal
Markdown link to its `mNNN.md` file so repository-local link verification checks
the navigation target automatically.
