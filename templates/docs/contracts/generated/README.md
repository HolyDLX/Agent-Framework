# Generated contract artifacts

These files are generated from project contracts, evaluation activities, and
executable `@covers(...)` declarations by
`agent-framework/tools/contracts/generate_traceability.py`.

Do not edit generated CSV files manually. `MANUAL-REVIEW` is an expected state
for inspection- or analysis-only requirements; it is not equivalent to an
unmet requirement. `PLANNED-AUTOMATED` is an explicit pre-implementation state
for automated evidence that has deliberately been deferred.
