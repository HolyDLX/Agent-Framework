# Review milestone

Use this skill for an independent review of a completed implementation
milestone.

1. Read the project root `AGENTS.md` and all framework workflow documents.
2. Read planning state, the milestone, its handover, and all authoritative
   specifications relevant to the implemented behavior.
3. Inspect implementation and tests independently; do not treat the handover as
   proof of correctness.
4. Compare contract requirements to evaluation activities and actual evidence.
5. Review `@covers(...)` mappings for both omissions and semantic overclaiming,
   and flag `PLANNED-AUTOMATED` requirements that belong to the completed
   milestone but still lack executable evidence.
6. Run complete container verification.
7. Write the milestone `-review.md` with findings ordered by severity and
   concrete follow-up work.
8. Update the roadmap when the review establishes required follow-up work.
