# Implement the current milestone

## Prerequisites

- Repository bootstrap is complete.
- `docs/planning/roadmap.md` identifies a current milestone.
- The milestone is sufficiently defined to implement without inventing product
  requirements.

## Prompt

> Read `agent-framework/skills/implement-milestone/SKILL.md` and implement the
> current milestone according to that skill.
>
> Treat project contracts and evaluation activities as authoritative for
> externally observable behavior. Use focused verification during development
> and run complete container verification before handover.
>
> Preserve unrelated work and report any requirement ambiguity instead of
> silently resolving it in implementation.
